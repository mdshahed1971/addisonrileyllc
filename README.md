# Addison Riley Premier

Build a premium, high-end website for:

ADDISON RILEY, LLC
FORENSICS • APPRAISAL • CONSTRUCTION

“Your most trusted experts in restoring hope.”

Phone: +1 850-776-5009
Email: contact@addisonriley.com

Do not invent certifications, years, clients, statistics, addresses or unsupported claims.

DESIGN:
Create a sophisticated architectural/editorial consulting website — NOT a generic roofing template.

Use an elegant balanced palette: graphite, soft stone, slate blue, muted steel and subtle blue gradients. Avoid an overly dark or overly white design.

Use large clean typography, strong spacing, cinematic construction/inspection imagery and premium visual composition.

SECTIONS:

1. HERO
Large headline:
“RESTORING HOPE.
PROVING WHAT MATTERS.”

Subtitle:
“Your most trusted experts in restoring hope.”

Buttons:
REQUEST A CONSULTATION
EXPLORE OUR EXPERTISE

Use cinematic image, subtle parallax and elegant text reveal.

2. ABOUT
“WHERE EXPERIENCE
MEETS EVIDENCE.”

Briefly explain the company’s Forensics, Appraisal and Construction expertise.

3. CONTAINER SCROLL
Create a major visual section:

“THE WORK BEHIND
THE EVIDENCE.”

“From roof inspections and loss documentation to large-scale construction projects, our work happens where the facts are found — in the field.”

Use the provided Aceternity ContainerScroll component and adapt it correctly for React + Vite + TypeScript. Do NOT use Next.js or next/image.

Use a replaceable construction/roof inspection image inside it.

4. EXPERTISE
Create premium editorial layouts for:
Forensics
Appraisal
Construction
Roofing
Engineering
Mitigation
Umpire

Avoid boring card grids.

5. SELECTED FIELD WORK
Show these as selected field work examples:
75,000 SQ. FT. TPO ROOF REPLACEMENT — Texas City, TX
FIRE LOSS — Birmingham, AL
HOTEL INSPECTION — Fort Myers Beach, FL
MOLD CASE — Ohio
WATERFRONT RENOVATION — Destin, FL

Use large imagery and editorial layouts. Do not imply these are current projects.

6. CASE STUDIES / DOCUMENTATION
Large statement:
“DON’T JUST DESCRIBE
WHAT HAPPENED.
DOCUMENT IT.”

Add scroll-linked text reveal, image mask animation and subtle parallax.

7. PROCESS
01 INSPECT
02 DOCUMENT
03 EVALUATE
04 REPORT

8. WHO WE WORK WITH
Property Owners • Attorneys • Public Adjusters • Construction Professionals • Commercial Clients

9. FINAL CTA
“WHEN THE DETAILS MATTER,
EXPERTISE MATTERS.”

REQUEST A CONSULTATION

10. FOOTER
ADDISON RILEY, LLC
FORENSICS • APPRAISAL • CONSTRUCTION

Include phone, email, navigation and a Facebook icon/link.

MOTION:
Use Framer Motion + Lenis.
Smooth scrolling, word/line text reveals, image masks, subtle parallax, scale transitions, staggered reveals, premium hover effects, sticky storytelling and navbar transformation.

Motion must feel cinematic, controlled and expensive — never excessive or bouncy.

TECH:
React + Vite + TypeScript + Tailwind CSS + Framer Motion + Lenis.

Fully responsive, accessible and fast.
Use replaceable stock images where real images are unavailable.
Keep the design clean and polished. Do not add unnecessary dependencies or sections.
